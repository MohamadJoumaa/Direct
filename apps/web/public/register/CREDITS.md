## Why these four

The Unsplash License grants copyright only. It explicitly does **not** grant
rights to trademarks/logos appearing in an image, or to the likeness of
recognisable people — those would need the owner's or the person's permission.
So each file was checked at full resolution for both:

| File | Recognisable face | Visible logo / trademark |
| --- | --- | --- |
| `courier-night.jpg` | No — full-face helmet, visor down | No — plain box, background motion-blurred |
| `parcels-stack.jpg` | No — no people | No — plain boxes, blank tape |
| `parcel-care.jpg` | No — hand only | No — "FRAGILE HANDLE WITH CARE" is generic text |
| `handover.jpg` | Partial — face cropped above the nose, eyes out of frame | No |

Replace like for like if these ever change: check the full-size file, not a
thumbnail. A logo that is illegible at 900px can be perfectly readable at 1200.
